Harmony 525

Read a Logitech Harmony 525 over USB, or open a saved .EZHex; see and try its devices, activities and screens; change them; write the result back. Everything happens in this browser.

Experimental. Use entirely at your own risk. A test version from a reverse engineering project, tried on one Harmony 525 only, the author's own. Writing to a remote can leave it not working, and there may be no way back. No warranty, no support; nobody behind this page is responsible for a remote, or anything else, that it damages. Not affiliated with or endorsed by Logitech. Always keep the backup file it saves.

Add a device

    Or learn it: for each 525 key the device should answer, press Learn, point the device's own remote at the bottom end of the 525 (below the keypad, a hand's width away) and tap that key on it. Any infrared works. Or type an NEC command, with the NEC address below. Keys left empty do nothing. Pointing at a row lights its key on the drawn remote.

      Writing to the remote

      Write does what Concordance does: it invalidates the old configuration, erases only the configuration's own flash (never the firmware), writes, reads everything back and compares, restarts the remote and sets its clock. Before it starts, the page saves what it read from the remote as a backup file. Only possible after reading the remote in this page. Without this page: concordance --no-web --write-config file.EZHex.
