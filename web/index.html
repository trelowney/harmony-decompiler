Harmony 525

Reads a Logitech Harmony 525 over USB in this browser, or opens a saved .EZHex, shows its devices, activities and screens, changes them, and writes the result back the way Concordance does. Nothing is sent anywhere but to the remote, and nothing is written to it unless you tick the box and press Write.

Experimental. Use entirely at your own risk. This is a test version from a reverse engineering project. It has been tried on one Harmony 525 only, the author's own, and on nothing else. Writing to a remote can leave it not working, and there may be no way back. There is no warranty and no support, and nobody behind this page is responsible for a remote, or anything else, that it damages. Not affiliated with or endorsed by Logitech. Always keep the backup file it saves.

    Add a device

    For each 525 key the device should answer, press Learn, point the device's own remote at the bottom end of the 525 (below the keypad, a hand's width away) and tap that key on it. Any infrared works: NEC is recognised and shown, anything else is kept as it was received. Or type an NEC command, with the NEC address below. Keys left empty do nothing.

    Write to the remote

    Writes the configuration on show to the remote the way Concordance does: it invalidates the old one, erases only the configuration's own flash (never the firmware), writes, reads everything back and compares, restarts the remote and sets its clock. Before it starts, the page saves what it read from the remote as a backup file. Only possible after reading the remote in this page.

    The write controls are in the bar at the top, which stays in view.
