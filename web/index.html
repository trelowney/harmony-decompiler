Nothing is sent anywhere but to the remote, and nothing is written to it unless you tick the box and press Write.

Write to the remote

Writes the configuration on show to the remote the way Concordance does: it invalidates the old one, erases only the configuration's own flash (never the firmware), writes, reads everything back and compares, restarts the remote and sets its clock. Before it starts, the page saves what it read from the remote as a backup file. Only possible after reading the remote in this page.

The write controls are in the bar at the top, which stays in view.
