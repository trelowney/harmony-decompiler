Activities

Point at a row to see where it sits on the remote. Press keys on the drawn remote to try the configuration: it shows what each key would send, and the row it belongs to lights up. Dimmed keys do nothing on the screen on show.

Add or edit a device

Pick a device to change what its keys send: each key shows what it sends now; Learn, type or pick from the database to change one, × to make it send nothing. Keys left as they are keep what they send.

    Or learn it: for each 525 key the device should answer, press Learn, point the device's own remote at the bottom end of the 525 (below the keypad, a hand's width away) and tap that key on it. Any infrared works. Or type an NEC command, with the NEC address below, or paste a Pronto hex code (0000 006D …, from a forum or an old database). Keys left empty do nothing. Pointing at a row lights its key on the drawn remote.

    Keep a device's power state

    The remote then knows whether the device is on: activities can switch it on, Off and the other activities switch it off, and nothing is sent when it already is. A power toggle is both on and off. Only devices without one are listed.

    Delete a device

    It goes from every Devices screen. Activities that use it no longer switch it or send to it.

      Configuration

      Writing to the remote

      Write does what Concordance does: it invalidates the old configuration, erases only the configuration's own flash (never the firmware), writes, reads everything back and compares, restarts the remote and sets its clock. Before it starts, the page saves what it read from the remote as a backup file. Only possible after reading the remote in this page. Without this page: concordance --no-web --write-config file.EZHex.
